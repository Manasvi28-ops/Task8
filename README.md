# Task8
Superstore Sales Dashboard – Power BI Project
This project showcases an interactive dashboard built in Power BI, focused on analyzing sales data by region, month, and sub-category. The goal was to clean the data, create meaningful visuals, and extract actionable insights.

Dataset
File Used: Superstore_Sales.csv
Key Columns:
Order Date ,Region ,Category ,Sub-Category ,Sales

Data Preparation
Data Cleaning:  Removed any null or irrelevant values
                Checked for inconsistencies in Region, Category, and Sub-Category names

Date Formatting: Transformed Order Date to Month-Year format for time-based analysis

Visualizations Created
Line Chart – Sales Over Time (Month-Year)
Bar Chart – Sales by Region
Donut Chart – Sales by Sub-Category

A slicer was also added to filter visuals by Region or Category, and color coding was used to highlight top-performing segments.

Key Insights
West Region recorded the highest sales across all categories (Bar Chart)
November showed the peak in overall sales (Line Chart)
Binders emerged as the top-selling sub-category (Donut Chart)
Furniture category had its highest sales in December (Line + Filtered View)
